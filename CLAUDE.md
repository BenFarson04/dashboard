# Dashboard Project

This is Ben's personal productivity dashboard.

Purpose:
- Morning dashboard
- Calendar overview
- Email overview
- Daily AI briefing
- News
- Future Spotify integration

Design Rules:
- Maintain dark theme.
- Keep dashboard card layout.
- Do not redesign layout unless requested.
- Prefer React functional components.
- Keep dependencies minimal.

Security:
- Never store API keys in source code.
- Never commit secrets.
- Use environment variables.

Testing:
- Run npm run build before completing work.
